Mini Chat App

A simple real-time chat application built with Flutter. The app allows users to authenticate with Google, chat with other users, and switch between light and dark themes.

Features
🔐 Google Sign-In — Log in using your Google account.
💬 One-on-One Chat — Send and receive messages with other users.
🌙 Dark Mode — Switch between light and dark themes.
🔥 Firebase — Firebase is used for authentication and backend services.
🎯 GetX — Used for state management and application logic.
Tech Stack
Flutter
Dart
Firebase
GetX
Google Sign-In
Overview

This project was created as a minimal chat application to practice building a Flutter app with Firebase authentication and real-time communication.

Users can sign in using their Google account, select another user, and have a one-on-one conversation. The application also supports both light and dark themes for a more comfortable user experience.
